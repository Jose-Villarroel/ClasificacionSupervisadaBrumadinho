# Base de 72 polígonos

Copia congelada de la versión anterior a la ampliación, extraída del commit
`845f00d` del repositorio. Se usa solo para reproducir la comparación entre la
versión de 72 y la de 88 polígonos.

| Archivo | Contenido |
|---|---|
| `training_dataset.tsv` | Píxeles de los 72 polígonos originales |
| `split.csv` | División original: 48 polígonos de entrenamiento y 24 de prueba |
| `metrics_summary.csv` | Métricas iniciales de los seis modelos |
| `per_class_SVM.csv` | Métricas por clase de la SVM en la prueba original |
| `per_class_ANN.csv` | Métricas por clase de la ANN en la prueba original |

No se usa para entrenar el modelo final de la Fase 3.
